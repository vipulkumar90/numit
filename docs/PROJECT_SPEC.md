# Project Specification

## Goal

Build a modern, mobile-first multiplayer party game web application.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Supabase (future)

## Principles

- Mobile first
- Responsive design
- Reusable components
- Clean architecture
- Strong TypeScript typing
- Accessibility where practical
- Modular file structure

## Initial Scope

- Application shell
- Routing
- Design system
- Theme
- Home page
- 404 page

Gameplay will be implemented in future iterations.
