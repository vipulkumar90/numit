# Design System

## Visual Style

Cute, colorful, playful, modern Japanese-inspired UI.

## Design Goals

- Friendly
- Soft
- Rounded
- Vibrant
- Clean
- Minimal clutter

## Border Radius

Large rounded corners.

## Shadows

Soft shadows only.

## Buttons

- Rounded
- Large touch targets
- Smooth hover animation
- Clear disabled state

## Cards

Floating appearance.

Consistent padding.

Rounded corners.

## Icons

Simple outlined icons.

## Spacing

Use consistent spacing throughout the application.

## Animations

Fast and subtle.

Avoid excessive motion.

## Theme

Support Light Mode.

Dark Mode should be easy to add later.
